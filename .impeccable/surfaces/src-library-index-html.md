# Bibliothèque musicale — extension de Nolys

Mode : Operate. Grande fenêtre dédiée confirmée par l’utilisateur, fichiers lus sur place.

## Direction contract

THESIS : ranger et écouter une collection personnelle ; la fenêtre et l’Island partagent une seule lecture.

OWN-WORLD : reprendre le charbon, le cuivre, Inter, Phosphor et les contrôles arrondis des réglages Nolys.

STORY : importer, retrouver des titres, composer une playlist, écouter. Prévoir collection vide, import, absence de résultat et fichier déplacé.

FIRST VIEWPORT : navigation à gauche, import en haut à droite, liste de titres centrale et lecteur persistant en bas. L’import conduit l’état vide.

FORM : extension du shell Nolys existant à navigation latérale ; fenêtre reliée à l’Island choisie par l’utilisateur. SEED REFERENCE : sans objet, composition héritée.

FINISH : unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
