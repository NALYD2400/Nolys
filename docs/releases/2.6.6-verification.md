# Vérification Nolys 2.6.6 — 5 novembre 2026

- `npm run check` : 91 tests JavaScript, compilation de l’interface et 90 tests Rust réussis ; 7 tests matériels ou dépendant du moteur restent ignorés.
- `npm run check:browser` : les 13 suites réussissent, avec Microsoft Edge et un pont natif simulé. Elles couvrent les menus, le centre de contrôle, les fichiers, la bibliothèque, le lecteur, Replay, les aperçus, les réglages, le placement et les minuteurs.
- Placement dans une instance Windows de diagnostic avec données et profil WebView isolés : commandes stables à l’écran de 65 à 150 %, aperçu conservé au changement de taille, absence du texte d’aide, bord supérieur de la pilule à la coordonnée 0. Le style Windows `WS_EX_TRANSPARENT` peut être activé pendant le placement ; les zones cliquables envoyées par l’UI comprennent la pilule et la barre, pas toute la fenêtre.
- Restauration des réglages : le parcours navigateur vérifie les erreurs de stockage, les retours arrière et l’annulation d’un import. Les événements de configuration périmés de cette fenêtre sont rejetés, même s’ils attendent déjà dans la file de rendu.
- `npm run check:audit` : aucune vulnérabilité npm ; contrôle RustSec réussi avec les 7 avertissements de dépendances déjà autorisés par la configuration du dépôt.
- Les SHA-256 des 27 sources graphiques correspondent à `branding/assets.json`.

Le serveur HTTP de la fixture Rust attend maintenant la fin des en-têtes de requête avant de répondre et exclut la mise en cache. Deux passages complets réussissent après cette correction, sans changer le client HTTP de production.

Ces contrôles ne valident pas les captures matérielles longues, tous les périphériques audio, la veille ni tous les écrans à DPI mixtes. La matrice correspondante reste dans `tools/tests/replay-validation.md`. Le test de placement natif utilise un exécutable de diagnostic ; il ne constitue pas un essai de la CSP du binaire release. La signature de l’installateur et le manifeste de mise à jour sont contrôlés séparément avec `node tools/verify-release.mjs` avant publication.
