# Identité visuelle Nolys

## Marque validée — 5 novembre 2026

Logo Orbite : deux courbes opposées en verre blanc nacré, ouverture diagonale, tuile bleu nuit et reflets bleus/violets. La forme validée est celle de gauche dans la comparaison avec la variante Island. Conserver son mouvement ; ne pas imposer une initiale N ou une capsule au centre.

## Icônes des modules — 13 novembre 2026

Les modules et les raccourcis proposés utilisent des images générées par IA en verre blanc nacré sur fond transparent, sans tuile permanente. Elles sont partagées entre le menu, le clic droit, les réglages, le centre de contrôle et les états compacts. Explorateur et Réglages Windows réutilisent les images Fichiers et Réglages ; les choix personnels Dossier et Musique réutilisent également ces symboles. Le survol du grand menu révèle une surface translucide discrète ; les commandes personnelles conservent l’icône choisie. Les couleurs fonctionnelles, notamment le point rouge REC, restent présentes. Le logo Orbite de l’application reste inchangé.

Les images à contours générées se trouvent dans `src/public/assets/modules/glass-outline/` ; la première série générée est conservée dans `src/public/assets/modules/glass/`. Les anciens PNG nacrés sont conservés dans `src/public/assets/modules/neutral/` et existent également dans le dossier personnel `icon/Nolys`. Aucune migration des préférences n’est nécessaire.

## Vérification

Vérifier les exports Windows, le logo en 32 px, le menu à la taille native, le lecteur sans pochette et les réglages. Les captures dans `.impeccable/review/branding-orbite/` proviennent du navigateur avec pont natif simulé ; elles ne prouvent pas le rendu d’une installation publiée.
